# PowerPulse: Adaptive Low-Power-Aware RISC-V System-on-Chip

**PowerPulse** is an adaptive, low-power-aware System-on-Chip (SoC) designed in synthesizable SystemVerilog/Verilog, built around the **Western Digital VeeR EL2** RISC-V core (RV32IMC) and an AXI4 interconnect fabric.

The SoC features hardware-driven, autonomous peripheral activity management that monitors peripheral usage, dynamically gates clocks/enables during inactivity, and automatically restores full operation upon detecting valid wake-up events—all without software polling overhead.

---

## 2. Memory Map & Peripheral Slots

All addresses are single-source-of-truth parameterized in `config/soc_config.yaml` and generated by `tools/gen_interconnect.py`.

| Slot | Module | Base Address | Size | Description |
|---|---|---|---|---|
| **0** | `imem` | `0x8000_0000` | 256 KiB | Instruction Memory (Hex-loaded RAM) |
| **1** | `dmem` | `0x8004_0000` | 256 KiB | Data Memory (Application stack/heap) |
| **2** | `uart` | `0x4000_0000` | 4 KiB | 16550-compatible serial UART (115200 8N1) |
| **3** | `timer`| `0x4000_1000` | 4 KiB | 32-bit reloadable countdown timer with IRQ |
| **4** | `gpio` | `0x4000_2000` | 4 KiB | 8-bit GPIO with 2-flop sync & edge detection |
| **5** | `hap`  | `0x4000_3000` | 4 KiB | Hardware Activity Profiler (Inactivity counters) |
| **6** | `ppmc` | `0x4000_4000` | 4 KiB | Peripheral Power Management Controller (FSM) |
| **7** | `awec` | `0x4000_5000` | 4 KiB | Autonomous Wake-Up Event Controller |
| **8** | `status`| `0x4000_F000`| 4 KiB | Simulation Status Device (PASS/FAIL reporter) |

## 3. Autonomous Power Management Subsystem

The SoC implements a closed-loop hardware activity management sequence:

1. **Activity Monitoring:** `HAP` monitors transaction signals from UART, Timer, and GPIO. Whenever a peripheral is accessed or active, its inactivity counter resets to zero.
2. **Idle Detection:** If a peripheral remains inactive for longer than `HAP_IDLE_TH` clock cycles, `HAP` asserts its corresponding `hap_idle` signal.
3. **Transition to LOW-ACTIVITY:** In autonomous policy mode, `PPMC` receives `hap_idle`, transitions the peripheral state machine from `ACTIVE` $\rightarrow$ `IDLE` $\rightarrow$ `LOW-ACTIVITY`, and pulls low the peripheral's `periph_enable` signal to gate switching activity.
4. **Wake-Up Event Detection:** `AWEC` independently monitors asynchronous wake triggers (UART RX incoming start bit, external GPIO pin edges, or scheduled Timer compare events).
5. **Automatic Peripheral Restoration:** Upon detecting a valid wake event, `AWEC` latches the event source ID and issues `wakeup_req` to `PPMC`. `PPMC` automatically transitions the peripheral state back to `ACTIVE` and restores clocks within 1 cycle.
6. **Software Handling:** The processor reads the captured wake source from `AWEC` and handles incoming traffic with zero data loss.

## 5. Software Stack & Drivers

Pre-built C drivers are available in `sw/common/`:
* `pp_uart.h`: Serial character/string transmission, line status polling.
* `pp_timer.h`: Timer period programming, countdown inspection, interrupt clearing.
* `pp_gpio.h`: Pin direction, input reading, output driving, and edge-interrupt configuration.
* `pp_hap.h`: Inactivity threshold configuration and idle flag monitoring.
* `pp_ppmc.h`: Power state inspection (`ACTIVE`, `IDLE`, `LOW-ACTIVITY`) and policy selection.
* `pp_awec.h`: Wake source enable masking, event latch status, and event acknowledgement.
* `pp_status.h`: Simulation PASS/FAIL reporting.

Demo firmware is located in `sw/tests/power_demo/power_demo.c`.

## 6. Simulation & Tool Flow (Synopsys VCS & Verdi)

### 6.1. Prerequisites & Generation
On Linux or in your lab environment:
```bash
# Clone the repository
git clone <repo_url> PowerPulse
cd PowerPulse

# Regenerate all memory maps, packages, and interconnect RTL
python3 tools/gen_interconnect.py
```

### 6.2. Running Core-in-Loop SoC Tests
```bash
# Run UART hello bring-up test
make run T=soc/uart_hello

# Run full autonomous power management demo
make run T=soc/power_demo

# Run full regression suite
make regress
```

### 6.3. Running the UVM Testbench Suite
```bash
cd tb/uvm

# Compile design and UVM testbench
make comp

# Run default UVM test (powerpulse_base_test)
make run

# Run autonomous power stress test
make power_test

# Debug waveforms in Synopsys Verdi
make verdi
```
